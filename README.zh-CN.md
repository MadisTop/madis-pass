# Madis Pass

> **状态：v1 已实现（Windows x64）。尚无官方 GitHub / Gitee Release，未经第三方安全审计。**
> 本仓库只包含产品文档，不含源码、私钥、工作流或内部调试产物。

单机、完全离线、个人自用的低资源占用桌面密码管理器。用一个主密码解锁一个本地密文库，通过托盘与全局快捷键快速查找并复制密码。

发布者 **Madis**；应用标识 **`top.madis.pass`**；正式二进制 **`madis-pass`**；版本 **0.1.0**。

## v1 已实现的能力

以下功能已落地，并受单元测试与格式回归向量覆盖：

- 创建 / 解锁 / 锁定密文库；修改主密码。
- 条目增删改查、收藏、标签、备注、自定义字段与本地搜索。
- CSPRNG 密码生成器；复制密码后自动清空剪贴板。
- 密文备份与恢复；原子写入并轮换上一版 `pass.mpv1.bak`。
- 空闲锁定、会话锁定（连续两次确认）、手动锁定、退出锁定。
- 托盘、快速搜索浮窗、`Ctrl+Alt+P` / `Ctrl+Alt+L` 全局快捷键。
- 便携模式、浅色 / 深色主题、简体中文 / 英文。

**明确不做**：云同步、账号、浏览器扩展、系统级自动填充、TOTP / Passkey、附件、条目历史、多人共享、遥测、在线更新、KDBX 写入、移动端。

## 设计目标与测量边界

- **占用资源非常小**：Rust + Slint 软件渲染；无 WebView、无 GPU 运行时、无数据库引擎、无网络客户端。单文件密文，解锁后仅保留内存索引。
- **v1 完全离线**：无账号、无云同步、无遥测、无更新检查，主程序不主动发起外链请求。
- **单文件密文库**：整库存于 `pass.mpv1`；备份即同格式密文副本。
- **快速锁定**：空闲 / 会话锁定自动锁定，剪贴板自动清空，密码明文不进入界面列表模型。
- 资源数字只在受控测量报告（见私有源码仓验收文档）中给出。解锁瞬间按设计占用 64 MiB 以上内存并消耗 CPU，这是抗离线爆破成本，不是性能缺陷；该数值与空闲态内存分开记录，不作「零 CPU」宣称。

## 公开的密文格式：可独立验证

程序源码私有，因此格式以独立规范 + 公开测试向量的形式公开：

- [MPV1 密文格式规范](docs/MPV1-密文格式规范.md)：字节布局、Argon2id 参数、XChaCha20-Poly1305 用法、规范化 JSON schema、校验步骤与错误条件。
- [MPV1 公开测试向量](docs/MPV1-测试向量/README.md)：固定假数据库、测试主密码、错误密码、九组篡改 / 截断 / 追加样本，以及机器可读的 `manifest.json`。
- `madis-pass-probe`：独立编译的命令行工具，用独立解析路径校验 88 字节头与 Poly1305 标签，随 Windows 便携包分发；`self-test` 可重放全部向量。

参数摘要：Argon2id v1.3（`m=64 MiB`、`t=3`、`p=4`）→ HKDF-SHA256 → XChaCha20-Poly1305，88 字节头整体作为 AAD。测试向量与自检是**回归验证，不是安全审计**。

## 安全边界（请务必阅读）

- **程序源码私有**。公开的是格式规范、测试向量、独立校验工具与下述威胁模型；产品**未经第三方安全审计**。
- **不提供主密码找回、重置或提示**。遗忘主密码即数据不可恢复，请自行备份密文文件。
- **不防御**：本机管理员或同用户权限的恶意软件、键盘记录器、屏幕截图/录屏、剪贴板管理器与剪贴板历史、远程桌面会话、系统页面文件 / 休眠文件 / 崩溃转储、冷启动攻击、文件系统快照、云同步历史副本、改密前生成的旧密文备份、硬件调试与侧信道攻击。
- 剪贴板自动清空（默认 15 秒）只在内容仍为本程序写入时执行，无法清除其他软件已保存的副本。
- v1 未实现明文 CSV 导出；若后续提供，该文件不加密，使用后须安全删除。
- 不作「零 CPU」「不可破解」「已审计」等宣称。

## 数据位置

| 平台 | 数据目录 |
| --- | --- |
| Windows | `%LOCALAPPDATA%\Madis\Pass\Data` |
| macOS | `~/Library/Application Support/Madis/Pass/Data` |
| Linux | 有效绝对 `$XDG_DATA_HOME/Madis/Pass/Data`，否则 `~/.local/share/Madis/Pass/Data` |

目录内只有 MPV1 密文（`pass.mpv1`、上一版 `pass.mpv1.bak`）与无秘密的 `state.json` / `ui.json`，**磁盘上不存在明文库文件**。macOS / Linux 构建尚未产出。

便携模式使用可执行文件旁的 `Data/`，请勿放在云同步盘或共享目录；`--data-file <路径>` 可指定独立密文文件，与便携模式同时使用时会被明确拒绝。

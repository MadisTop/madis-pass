# Madis Pass

> **状态：设计阶段。尚未发布、尚无下载、尚无实现代码。**
> 本仓库只包含产品文档，不含源码、私钥、工作流或内部调试产物。

单机、完全离线、个人自用的低资源占用桌面密码管理器。用一个主密码解锁一个本地密文库，通过托盘与全局快捷键快速查找并复制密码。

发布者 **Madis**；应用标识 **`top.madis.pass`**；正式二进制 **`madis-pass`**。

## 设计目标

- **占用资源非常小**：Rust + Slint 软件渲染；无 WebView、无 GPU 运行时、无数据库引擎、无网络栈。
- **v1 完全离线**：无账号、无云同步、无遥测、无更新检查、无任何外链请求。
- **单文件密文库**：整库存于 `pass.mpv1`；备份即同格式密文副本。
- **快速锁定**：空闲 / 会话锁定 / 睡眠自动锁定，剪贴板自动清空，密码明文不进入界面模型。

## v1 计划功能

创建 / 解锁 / 锁定密文库、修改主密码、条目增删改查与本地搜索、CSPRNG 密码生成器、复制并自动清空剪贴板、加密备份与恢复、便携模式、托盘与全局快捷键、浅色/深色、简中/英文。

**明确不做**：云同步、账号、浏览器扩展、系统级自动填充、TOTP / Passkey、附件、条目历史、多人共享、AI、遥测、在线更新、KDBX 写入、移动端。

## 公开的密文格式

程序源码私有，但密文格式完全公开，便于第三方独立验证：

- [MPV1 密文格式规范](docs/MPV1-密文格式规范.md)：字节布局、Argon2id 参数、XChaCha20-Poly1305 用法、规范化 JSON schema、校验步骤与错误条件。
- 规划中的 `madis-pass-probe` 是独立编译的命令行工具，用独立解析路径校验头与认证标签。固定测试向量将随首个实现一并公开；**目前尚无测试向量**。

参数摘要：Argon2id v1.3（`m=64 MiB`、`t=3`、`p=4`）→ HKDF-SHA256 → XChaCha20-Poly1305，88 字节头整体作为 AAD。解锁瞬间按设计占用 64 MiB 以上内存并消耗 CPU，这是抗离线爆破的成本，不是性能缺陷。

## 安全边界（请务必阅读）

- **程序源码私有**。公开的是格式规范、规划中的独立校验工具与下述威胁模型；产品**未经第三方安全审计**。
- **不提供主密码找回、重置或提示**。遗忘主密码即数据不可恢复，请自行备份密文文件。
- **不防御**：本机管理员或同用户权限的恶意软件、键盘记录器、屏幕截图/录屏、剪贴板管理器与剪贴板历史、远程桌面会话、系统页面文件 / 休眠文件 / 崩溃转储、冷启动攻击、文件系统快照、云同步历史副本、改密前生成的旧密文备份、硬件调试与侧信道攻击。
- 剪贴板自动清空（默认 15 秒）只在内容仍为本程序写入时执行，无法清除其他软件已保存的副本。
- 若后续提供明文 CSV 导出，该文件不加密，使用后须安全删除。
- 不作「零 CPU」「不可破解」「已审计」等宣称。任何性能数字都必须来自尚不存在的受控测量报告。

## 数据位置

| 平台 | 数据目录 |
| --- | --- |
| Windows | `%LOCALAPPDATA%\Madis\Pass\Data` |
| macOS | `~/Library/Application Support/Madis/Pass/Data` |
| Linux | 有效绝对 `$XDG_DATA_HOME/Madis/Pass/Data`，否则 `~/.local/share/Madis/Pass/Data` |

Windows 安装目录为 `%LOCALAPPDATA%\Programs\Madis\Pass`；安装与数据严格分离，卸载保留用户数据。便携模式使用可执行文件旁的 `Data/`，请勿放在云同步盘或共享目录。

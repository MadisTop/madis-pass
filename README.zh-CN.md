# Madis Pass

> **状态：v1 已实现，四目标能力已落地；仅 Windows x64 便携包经本机验证。尚无官方 GitHub / Gitee Release，未经第三方安全审计。**
> 本仓库只包含产品文档与公开分发契约，不含源码、私钥、工作流或内部调试产物。

单机、个人自用的低资源占用桌面密码管理器。用一个主密码解锁一个本地密文库，通过托盘与全局快捷键快速查找并复制密码。**密文库全程离线**；自动更新是唯一独立的出站通道，且当前默认关闭。

发布者 **Madis**；应用标识 **`top.madis.pass`**；正式二进制 **`madis-pass`**；版本 **0.1.0**。

## 已实现的能力

- 创建 / 解锁 / 锁定密文库；修改主密码。
- 条目增删改查、收藏、标签、备注、自定义字段与本地搜索。
- CSPRNG 密码生成器；复制密码后自动清空剪贴板。
- 密文备份与恢复；原子写入并轮换上一版 `pass.mpv1.bak`。
- 空闲锁定、会话锁定（连续两次确认）、手动锁定、退出锁定。
- 托盘、快速搜索浮窗、`Ctrl+Alt+P` / `Ctrl+Alt+L` 全局快捷键（Windows）。
- 便携模式、`--data-file` 指定独立密文库。
- **暗色模式三态**：跟随系统 / 浅色 / 深色，选择后即时生效并持久化。
- **中英文三态**：跟随系统 / 简体中文 / English，界面静态文案与运行时提示同步切换，主窗与快速搜索浮窗一致。
- **签名自动更新客户端**：固定 HTTPS 端点、Minisign 验签、拒绝降级、包大小与 SHA-256 双重校验、后台检查、下载后退出安装并重启；便携模式只提示不安装。详见 [更新与版本策略](docs/更新与版本策略.md)。
- **四目标原生能力**：Windows / Linux / macOS 各自的系统主题、系统语言、空闲时间与开机自启探测。详见 [四平台交付说明](docs/四平台交付说明.md)。

**明确不做**：云同步、账号、浏览器扩展、系统级自动填充、TOTP / Passkey、附件、条目历史、多人共享、遥测、KDBX 写入、移动端。

### 自动更新当前是否可用

客户端检查、验签、下载与安装交接的**代码已实现并纳入测试**，但**服务尚未启用**：项目还没有独立的 Minisign 信任根、没有已签名的更新包、没有部署更新网关。编译期公钥为空，`enabled()` 返回 `false`，程序启动后不会发起任何网络请求，界面明确提示「自动更新服务尚未启用，请从下载页面手动更新」。

这不是网络故障，也不是「无更新」；只有完成信任根生成、离线签名流程、端点部署与实机升级闭环后才会启用。仓库中**不存在**任何私钥、`.minisig` 文件或伪造的公钥 / 包摘要。`release.config.json` 的 `updates.state` 为 `client-implemented-trust-root-not-configured`，`enabled` 与 `automaticInstall` 均为 `false`。

## 设计目标与测量边界

- **占用资源非常小**：Rust + Slint 软件渲染；无 WebView、无 GPU 运行时、无数据库引擎。单文件密文，解锁后仅保留内存索引。
- **密文库零网络**：`pass-crypto` / `pass-store` / `pass-service` 不链接 HTTP 栈，不读取密文库之外的任何凭据，不上报遥测或库标识。更新模块是独立编译单元，与密文链路隔离。
- **单文件密文库**：整库存于 `pass.mpv1`；备份即同格式密文副本。
- **快速锁定**：空闲 / 会话锁定自动锁定，剪贴板自动清空，密码明文不进入界面列表模型。
- 资源数字只在受控测量报告（见私有源码仓验收文档）中给出。解锁瞬间按设计占用 64 MiB 以上内存并消耗 CPU，这是抗离线爆破成本，不是性能缺陷；该数值与空闲态内存分开记录，不作「零 CPU」宣称。**空闲态内存尚未实测**。

## 公开的密文格式：可独立验证

程序源码私有，因此格式以独立规范 + 公开测试向量的形式公开：

- [MPV1 密文格式规范](docs/MPV1-密文格式规范.md)：字节布局、Argon2id 参数、XChaCha20-Poly1305 用法、规范化 JSON schema、校验步骤与错误条件。
- [MPV1 公开测试向量](docs/MPV1-测试向量/README.md)：固定假数据库、测试主密码、错误密码、九组篡改 / 截断 / 追加样本，以及机器可读的 `manifest.json`。
- `madis-pass-probe`：独立编译的命令行工具，用独立解析路径校验 88 字节头与 Poly1305 标签，随 Windows 便携包分发；`self-test` 可重放全部向量。

参数摘要：Argon2id v1.3（`m=64 MiB`、`t=3`、`p=4`）→ HKDF-SHA256 → XChaCha20-Poly1305，88 字节头整体作为 AAD。测试向量与自检是**回归验证，不是安全审计**。

## 安全边界（请务必阅读）

- **程序源码私有**。公开的是格式规范、测试向量、独立校验工具与下述威胁模型；产品**未经第三方安全审计**。
- **不提供主密码找回、重置或提示**。遗忘主密码即数据不可恢复，请自行备份密文文件。
- **不防御**：本机管理员或同用户权限的恶意软件、键盘记录器、屏幕截图/录屏、剪贴板管理器与剪贴板历史、远程桌面会话、系统页面文件 / 休眠文件 / 崩溃转储、冷启动攻击、文件系统快照、云同步历史副本、改密前生成的旧密文备份、硬件调试与侧信道攻击。
- 剪贴板自动清空（默认 15 秒）只在内容仍为本程序写入时执行，无法清除其他软件已保存的副本。
- v1 未实现明文 CSV 导出；若后续提供，该文件不加密，使用后须安全删除。
- 自动更新只接受编译期固定端点与固定信任根下的签名包；即便如此，它也不构成对供应链、本机恶意软件或签名私钥泄露的防护。
- 不作「零 CPU」「不可破解」「已审计」等宣称。

## 数据位置

| 平台 | 数据目录 |
| --- | --- |
| Windows | `%LOCALAPPDATA%\Madis\Pass\Data` |
| macOS | `~/Library/Application Support/Madis/Pass/Data` |
| Linux | 有效绝对 `$XDG_DATA_HOME/Madis/Pass/Data`，否则 `~/.local/share/Madis/Pass/Data` |

目录内只有 MPV1 密文（`pass.mpv1`、上一版 `pass.mpv1.bak`）与无秘密的 `state.json` / `ui.json`，**磁盘上不存在明文库文件**。

便携模式使用可执行文件旁的 `Data/`，请勿放在云同步盘或共享目录；`--data-file <路径>` 可指定独立密文文件，与便携模式同时使用时会被明确拒绝。更新只替换程序文件，**不改动、不删除用户数据目录**。

## 四目标交付与下载入口

目标矩阵为 Windows x64 / Linux x64 / macOS Intel / macOS ARM，共九种安装包格式（NSIS、MSI、AppImage、deb、rpm、dmg、app.tar.gz）。当前**只有 Windows x64 便携 ZIP 在本机生成并验证**，四目标原生安装包、构建仓 CI 与官方 Release 均为模板 / 未验收状态，详见 [四平台交付说明](docs/四平台交付说明.md)。

目前**没有官方 Release**。正式发布后请只使用本仓库的 GitHub / Gitee 官方发布页，不使用来源不明的转载包。`SHA256SUMS` 仅用于检测下载损坏，不是数字签名。

私有源码仓的 `release/windows/构建便携包.ps1` 可在本机生成 Windows x64 便携 ZIP，内含主程序、本说明、许可文本、格式规范、独立校验工具与 `SHA256SUMS.txt`。本机便携包**未签名**（`not-verified`），也不是官方发布。

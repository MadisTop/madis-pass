# 四平台交付说明

本文件说明 Madis Pass（identifier `top.madis.pass`，当前版本 `0.1.0`）的**目标**四目标九格式交付清单、数据目录与安装方式。

> **状态：能力已实现，交付模板待验收。** 当前仅 Windows x64 **便携包**由私有源码仓 `release/windows/构建便携包.ps1` 在本机生成并经本机验证（未签名、非官方 Release）。四目标原生安装包（NSIS / MSI / AppImage / deb / rpm / dmg / app.tar.gz）**全部为模板文件**，尚未由 CI 构建、尚未经实机安装/升级/卸载验收，也未创建任何官方 Release。
>
> 客户端侧的跨平台能力（系统主题、系统语言、空闲时间、开机自启、密文库路径、自动更新）已落地；纯 Rust 层已在 Linux x64 / macOS Intel / macOS ARM 三个目标上通过 `cargo check` 类型检查。**Windows 本机缺少 fontconfig sysroot 与 C 编译器，无法完成桌面 UI 的非 Windows 编译**，该部分只能由 CI 原生 runner 验证，不得据此声称 Linux / macOS 构建已通过。

## 四目标九格式清单

| 目标 | Runner | Rust target | 格式 | 候选文件名 |
| --- | --- | --- | --- | --- |
| windows-x64 | windows-2022 | `x86_64-pc-windows-msvc` | NSIS `.exe` | `madis-pass_0.1.0_windows-x64-setup.exe` |
| windows-x64 | windows-2022 | `x86_64-pc-windows-msvc` | MSI `.msi` | `madis-pass_0.1.0_windows-x64.msi` |
| linux-x64 | ubuntu-22.04 | `x86_64-unknown-linux-gnu` | AppImage | `madis-pass_0.1.0_linux-x64.AppImage` |
| linux-x64 | ubuntu-22.04 | `x86_64-unknown-linux-gnu` | deb | `madis-pass_0.1.0_linux-x64.deb` |
| linux-x64 | ubuntu-22.04 | `x86_64-unknown-linux-gnu` | rpm | `madis-pass_0.1.0_linux-x64.rpm` |
| macos-x64 | macos-15-intel | `x86_64-apple-darwin` | dmg | `madis-pass_0.1.0_macos-x64.dmg` |
| macos-x64 | macos-15-intel | `x86_64-apple-darwin` | app.tar.gz | `madis-pass_0.1.0_macos-x64.app.tar.gz` |

## 平台原生能力对照

| 能力 | Windows x64 | Linux x64 | macOS Intel / ARM |
| --- | --- | --- | --- |
| 暗色模式「跟随系统」 | 注册表 `AppsUseLightTheme` | `GTK_THEME` / KDE `kdeglobals` / GNOME `gsettings` | `defaults read -g AppleInterfaceStyle` |
| 语言「跟随系统」 | `GetUserDefaultUILanguage` | `LC_ALL` → `LC_MESSAGES` → `LANG` → `LANGUAGE` 是否以 `zh` 开头 | `AppleLanguages`，回退 `LANG` |
| 系统空闲时间 | `GetLastInputInfo` | `xprintidle`（毫秒） | `ioreg -c IOHIDSystem` 的 `HIDIdleTime`（纳秒） |
| 会话锁定事件 | `OpenInputDesktop` 轮询 + 连续两次确认 | **降级**：不订阅原生事件，由应用层空闲锁定承担 | **降级**：同左 |
| 开机自启 | 注册表 Run 项 | XDG `autostart/top.madis.pass.desktop` | `~/Library/LaunchAgents/top.madis.pass.plist` |
| 全局快捷键 | `RegisterHotKey`（`Ctrl+Alt+P` / `Ctrl+Alt+L`） | **降级**：改用托盘入口 | **降级**：改用托盘入口 |
| 剪贴板 | 全平台统一实现，写入后回读比对再清空 | 同左 | 同左 |
| 密文库路径 | `%LOCALAPPDATA%\Madis\Pass\Data` | XDG 数据目录 | `~/Library/Application Support/Madis/Pass/Data` |

「降级」表示功能代码明确返回不支持或不可用，**不伪装成已实现**：Linux / macOS 没有原生会话事件订阅与全局热键注册，界面会提示使用托盘，自动锁定仍由空闲计时器保障。所有外部命令探测都有超时与优雅失败，命令缺失时返回「不可用」而不是 0，避免把「不支持」误读为「用户刚刚操作过」。

三态外观与三态语言（跟随系统 / 浅色或深色 / 中文或英文）在选择后立即生效并写入 `ui.json`；主窗、快速搜索浮窗与 Rust 运行时提示使用同一语言模式。

## 数据目录对照表

| 平台 | 安装目录（程序） | 数据目录（用户密文库） |
| --- | --- | --- |
| Windows | `%LOCALAPPDATA%\Programs\Madis\Pass` | `%LOCALAPPDATA%\Madis\Pass\Data` |
| macOS | 拖入 `/Applications` 或用户目录的 `Madis Pass.app` | `~/Library/Application Support/Madis/Pass/Data` |
| Linux | 系统包安装到 `/usr/bin/madis-pass`；AppImage 随身携带 | `$XDG_DATA_HOME/Madis/Pass/Data`，无有效值时回退 `~/.local/share/Madis/Pass/Data` |

数据目录只含 MPV1 密文 `pass.mpv1`、轮换备份 `pass.mpv1.bak` 以及非机密的 `state.json` / `ui.json`，**不写入明文口令库**。安装目录与数据目录彼此分离，卸载只移除程序与快捷方式，**完整保留用户数据**，不递归清理任何目录。便携模式改用可执行文件旁的 `Data/`，请勿放在云同步或共享目录。

## 各平台安装方式（目标，尚未实机验收）

| 格式 | 预期安装方式 |
| --- | --- |
| NSIS `.exe` | 双击运行当前用户安装器；程序正在运行时拒绝升级，需先从托盘彻底退出 |
| MSI `.msi` | `msiexec /i` 当前用户安装；`MajorUpgrade` 拒绝降级，升级前需退出程序 |
| AppImage | 赋予可执行位后直接运行；只设置包内 `LD_LIBRARY_PATH` |
| deb | `sudo apt install ./madis-pass_<版本>_linux-x64.deb` 或包管理器安装 |
| rpm | `sudo rpm -i madis-pass_<版本>_linux-x64.rpm`；`License` 由部署者提供，不 strip 已编译程序 |
| dmg | 打开后把 `Madis Pass.app` 拖入 Applications；未经签名与公证 |
| app.tar.gz | 解压得到 `Madis Pass.app`，供手动部署或归档，不自动安装 |

## 当前验收边界

- **已本机验证**：Windows x64 便携 ZIP（源码仓本机产物，未签名、非官方 Release）；全工作区测试、严格 clippy、release 构建、启动冒烟；自动更新客户端的状态机 / 验签 / 白名单 / 拒绝降级单元测试。
- **已静态验证**：`pass-core` / `pass-crypto` / `pass-store` / `pass-platform` / `pass-service` / `pass-probe` 六个纯 Rust crate 在 `x86_64-unknown-linux-gnu`、`x86_64-apple-darwin`、`aarch64-apple-darwin` 三个目标上 `cargo check --locked` 退出 0；构建仓打包骨架测试 11 项通过。这**不是**可运行构建。
- **模板待 CI/实机验收**：桌面 UI 的非 Windows 编译（本机缺 fontconfig sysroot 与 C 编译器）、上表九种原生安装包的实际生成、逐包解包回读、实机安装/升级/卸载保留数据、原生代码签名、Apple 公证、更新网关与正式发布。
- 官方 Release、真实包 SHA-256、签名与下载 URL 均不存在；`SHA256SUMS` 仅用于检测下载损坏，不是签名。
- 状态以 `release.config.json` 为准：所有 `packaging` / `nativeSigning` / `notarization` / `updater` 均为 `not-verified` 或 `not-applicable`，`release.state` 为 `implemented-not-published`，自动更新默认关闭。详见《更新与版本策略.md》。
